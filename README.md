# 🎵 Logic Music Website (React Project)

## 📌 Project Description
This is a responsive music website built using ReactJS.  
The project is dedicated to the artist Logic and showcases his biography, popular songs, albums, and official music platforms such as Spotify and YouTube.

The website is designed with a modern UI/UX approach and includes multiple pages for better user experience.

---

## 🚀 Features
- Multi-page React application (Home, Music, About, Contact)
- Responsive design (mobile + desktop)
- Music showcase with album covers
- Official links to Spotify and YouTube
- Clean and modern UI using Bootstrap and CSS
- Interactive components and hover effects

---

## 🛠️ Technologies Used
- ReactJS
- JavaScript (ES6)
- Bootstrap 5
- CSS3
- React Router DOM
- React Icons
- Git & GitHub for version control
